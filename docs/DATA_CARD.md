# Data card — Trash Gordon

## Provenance

Default examples are authored synthetic data generated by `lab/robot.py`. `data/sample-state.json` is an inspectable initialization. The implementation defines schemas, seed values and generation assumptions. AutoML additionally uses datasets supplied by installed scikit-learn; see `DATA_LICENSES.md`.

## Processing and partitions

Read the engine’s `evaluate` method and `docs/EXPERIMENTS.md` for the exact train/test or scenario partition. No assertion of generalization beyond that protocol is made.

## User data

Imports, state and generated media are local to `runtime/`. They are excluded from version control. Importing a file grants no redistribution rights. Review consent and ownership before publishing any additional dataset.

## Representativeness

Synthetic examples demonstrate mechanics; they do not establish the behaviour of real people, devices or organizations.
