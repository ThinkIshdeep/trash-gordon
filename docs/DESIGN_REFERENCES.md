# Design references

The redesign uses original HTML, CSS, canvas, SVG and software-rendered geometry. These references informed composition and interaction patterns; no reference screenshot is used as a working interface.

- [Layo’s map dashboard on Pinterest](https://www.pinterest.com/pin/3d-map-dashboard-in-2025--674414112987399654/): a dominant spatial surface with compact contextual overlays.
- [Industrial/spatial interface board](https://www.pinterest.com/piratalisoniha/nlmk/): industrial scene and control composition.
- [KENYMOOK — SEDA node-system concept](https://dribbble.com/shots/26500134-Ai-generation-of-a-node-system-for-generating-images-SEDA-Kit): inspectable node canvases.
- [Eddie Luong / Interactive Labs — courses dashboard](https://dribbble.com/shots/14755032-3D-Courses-Management-Dashboard): warmer, approachable educational composition.
- [Nixtio — analytics interface](https://dribbble.com/shots/21335569-Admin-Dashboard-Analytics-UI): readable data hierarchy.
- [Uroosa Arif — healthy kitchen inventory](https://dribbble.com/shots/26189400-Smart-Inventory-UI-for-Healthy-Kitchens): visually organized pantry content.

Public Pinterest search required sign-in in the research browser; the accessible references above and the original creators were used.
